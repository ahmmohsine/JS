# Exercices JavaScript

Ce dépôt rassemble mes exercices pour apprendre et pratiquer JavaScript, de la manipulation de formulaires à l’utilisation d’API.

## Exercices

### Formulaire d’inscription

Un formulaire HTML avec des champs pour le prénom, l’âge et le pays, ainsi qu’une case à cocher pour accepter les conditions d’utilisation.

Notions pratiquées :

- Écouter la soumission d’un formulaire avec `addEventListener`
- Empêcher l’envoi automatique avec `event.preventDefault()`
- Récupérer et valider les valeurs des champs
- Ajouter ou supprimer une classe CSS avec `classList`

### Affichage de Pokémon

Un petit programme qui récupère une liste de Pokémon depuis la [PokéAPI](https://pokeapi.co/). Le menu déroulant permet de choisir un Pokémon et d’afficher son nom et son image.

Notions pratiquées :

- Appels à une API avec `fetch`
- Fonctions asynchrones avec `async` et `await`
- Lecture de données JSON
- Création d’options HTML avec JavaScript
- Gestion d’un événement `change`

### Recherche de pays

Un programme qui recherche un pays à partir d’un nom saisi et affiche des informations comme sa capitale, son drapeau, sa population, sa monnaie et son continent.

Notions pratiquées :

- Récupération d’une saisie utilisateur
- Construction d’une URL de recherche
- Appel HTTP avec `fetch`
- Affichage des résultats dans la page
- Gestion des erreurs de recherche
